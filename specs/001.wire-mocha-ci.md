# 001 — Wire mocha and CI to a repo with no tests

## §1. Behaviour today

No test files, no test runner, `.github/workflows/dco.yml` only checks
commit sign-off (§1.1). This is a load-bearing shared engine (backtest
math consumed identically by main-app's backtest worker and both
dashboards' client-side backtest per this repo's own CLAUDE.md) with no
automated check that its output hasn't drifted (§1.2).

## §2. Desired behaviour

`npm test` runs a real mocha suite and exits 0 (§2.1). CI runs `npm
test` on every PR (§2.2). One placeholder spec proves the wiring is real
until actual coverage lands (§2.3) — real coverage of the engine math
itself is future work, out of scope here (this task is infrastructure
wiring, not authoring test cases for existing business logic).

## §3. Open questions / assumptions

- §3.1 mocha + chai, per this task's brief — same pattern as the sibling
  "no tests yet" repos wired in this sweep. Pre-authorized, not left
  open.

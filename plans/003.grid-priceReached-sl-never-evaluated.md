# 003 — plan

## Solution

In `src/grid/strategy/index.ts`, `Strategy.tpSl()`:

1. Break the `if / else if` chain into five independent `if` blocks, keeping
   the existing order (short TP → short SL → long TP → long SL →
   `valueChanged`). Order preserves TP-before-SL priority (§1.1); each block
   still `return`s on trigger, so at most one verdict is produced.
2. Flip the short stop-loss comparison to `lastPrice >= +slLowPrice` (§1.2).

Nothing else changes: the inner comparisons, the `valueChanged` maths, and
`closeBot` are untouched. This makes the backtester's `tpSl()` control flow
identical to the live engine's `main-app/core/src/bot/helper.ts:4057-4100`,
which is the oracle.

No new helper — this is a control-flow correction, not a formatting or
maths utility. (`REUSE BEFORE YOU WRITE`: nothing to reuse; grepped
`src/` and the live engine for an existing shared tp/sl predicate — there is
none, the two engines each own their copy.)

## JIT legacy tier

**Tier 0.** The method is already a pure decision function (no I/O, reads
`this.settings` + numbers, returns an enum). Extracting it further would be
scope creep and would break the deliberate line-for-line correspondence with
the live engine, which is what makes divergences like this reviewable.

## Blast radius

1. **Other call sites:** `tpSl()` is private and called from exactly one place,
   `processBar` (`src/grid/strategy/index.ts:973`). Grep confirms no other
   caller.
2. **`core/` submodule:** none — `backtester` has no `.gitmodules`.
3. **Cross-service contract (repo `CLAUDE.md` + root Danger List #13):** the
   engine is shared — main-app's backtest worker (:7515) and BOTH dashboards'
   client-side backtest import the same `@gainium/backtester`. Server and
   client therefore change *together* and stay identical; there is no
   server-only or client-only path. No input/result **type** changes, so no
   consumer needs a code change. Behaviour change is intentional and
   one-directional: runs that used to ignore a configured stop-loss now honour
   it. Previously-saved results are untouched (stored documents, not recomputed).
4. **Other tests on this path:** `test/grid-force-close-transaction.spec.ts`
   (spec 002) drives the same `tpSl → closeBot` path on a TP breakout and must
   stay green.

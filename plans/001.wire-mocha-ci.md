# 001 — Wire mocha and CI to a repo with no tests

## Build order

1. Add devDependencies: `mocha`, `chai`, `@types/mocha`, `@types/chai`,
   `ts-node` (not present — this repo only `tsc`-builds).
2. Add `test/placeholder.spec.ts`.
3. Add an npm `"test"` script: mocha over `test/**/*.spec.ts` via
   `ts-node/register`.
4. Add `.github/workflows/test.yml`: PR + push to `master` (default
   branch), Node 22, `npm ci`, `npm test`.
5. Verify `npm test` green locally.
